# Pocket 每日日程与语音随手记

计划系统通知已上线：按详细时间后台推送，完成/删除/修改计划同步更新提醒；每台设备在设置中分别开启系统通知，并可发送测试通知。计时控制与完成标记独立，保持原有规则。详见 NOTIFICATIONS.md 和 DELIVERY.md；实际 iPhone APNs 收件仍需用户启用后验收。

本次界面改为三个入口：每日日程、随手记、设置，默认打开每日日程。复用原有 SQLite 桌面桥及 Google Drive 账号，不更换站点和浏览器资料库。

## 每日日程

首次预置做饭、吃饭、收拾屋、睡觉、休息、学习、运动，使用固定 ID 与 seed 操作幂等初始化。编辑框只保留项目名称；固定项目卡片统一为网格中最高内容的高度，名称换行时所有卡片一起伸展；移除原有大块留白，保留至少 44px 的操作区域及右上角编辑入口。添加按钮在固定项目标题右侧，与计划项目标题行一致。显示顺序改为长按约 450 毫秒后拖动，松手保存并同步，滑动滚屏或取消拖动不修改顺序、不触发计时。键盘可在项目编辑入口按 Alt + 方向键排序。每周重复选项移除，原有重复日配置保留，新项目默认每天。修改名称、拖动顺序或移除项目后不会在下次打开重置，可新增项目。

点击项目开始，再点停止。已同步的设备共用当前活动项目，必须显式停止已知活动后才能启动另一项；不再自动切换。计时区左侧为暂停符号，暂停后变为继续符号；右侧为结束符号。暂停保留同一会话与任务锁，刷新后仍保留状态，暂停时间不累计。点击顶部计时卡片的内容或空白处可直接编辑本次备注，运行和暂停时都可用；暂停/继续、结束按钮独立操作。备注编辑不改动开始/结束时间和暂停区间，结束后沿用同一备注。结束时实际累计时长不超过 30 秒的计时写入删除墓碑，不计历史或统计；运行中的计时只显示在当前计时区。旧短会话也不纳入历史和统计。每段分别保存 UTC 开始/结束时间、设备与开始时区，界面显示时长、开始和结束；跨午夜按记录时区分配当日总时长。固定项目的当日累计用时与项目名称并列；计时历史也将有效时长紧邻名称显示，开始/结束时间放在下一行。每次已结束的计时可单独填写、编辑或清空多行备注，保存后显示在该段时间下方，支持同步与备份。结束后的时间可以修改或删除，旧会话保留开始时的项目名称快照。删除通过操作日志同步，时长统计忽略已删会话，重复删除不生成多余日志。

## 计划项目

固定项目下方提供单次计划，可添加、编辑名称/日期/备注或删除。新增可选 DDL 截止日期（按日）和可选详细时间（计划日期中的 HH:mm），可分别留空或清空；填写后显示在计划卡片上。DDL 使用 properties.plan_deadline，详细时间使用 properties.planned_start 的 UTC 时间戳及 properties.time_zone；跨设备保持计划时区。编辑其他字段保留已有时间，修改计划日期后同步调整已填写的详细时间，夏令时不存在的分钟拒绝保存。沿用原版 records.type=task、status=todo/done，复用原计划模块，不增加表或重复计数器。计划区展示未删除项目并保留未来计划，不受历史日期筛选影响，非今日项目显示计划日期；完成项收进“已完成计划”，取消勾选可重新打开。

计划可反复开始、暂停、继续及结束计时，每次为独立会话；结束计时不改变待办状态。计划名称右侧显示所有有效会话的累计用时，跨天累计、扣除暂停，短于等于 30 秒及删除的会话不计。日程当日统计仍只计算当日片段，固定项目保留各自当日累计。计划与固定项目共用已同步活动的锁定状态，暂停时仍不能切换。

只有勾选才完成计划；勾选正在计时或暂停的共享计划，会在同一事务结束当前段并标为完成，失败时两者一起回滚。可不计时直接完成，完成其他计划不影响当前任务。当前计划未结束前不能删除，历史会话不随计划删除而消失。计划及状态沿用 Google Drive、原 SQLite 白板交换与 JSON 备份，既有桌面任务可直接显示和继续计时。

## 随手记

文字保存后直接出现在下方历史列表，不限当前日；支持修改标题、正文、日期及删除。日程计时历史和随手记的编辑框使用相邻的“删除 / 保存”操作，取消按钮移除。各处编辑入口统一为条目右上角的 SVG 省略号，无圆形边框；保留无障碍编辑名称和触摸点击区域。长列表分批展开。草稿切页和刷新保留，本地写入不等待云端。

录音按钮使用浏览器麦克风与 MediaRecorder，优先选择 audio/mp4（m4a），其次使用 WebM/Opus。停止后自动保存当前文字和录音为同一条随手记；没有文字也可独立录音。单段上限 5 分钟或 4MB。进入后台时请求停止并保存，不承诺后台持续录音。权限拒绝或 API 不可用时保留文字并解释原因；保存失败时保留待保存录音并提供重试。

录音以 ArrayBuffer 二进制保存到 IndexedDB 的 media 表，避免某些 WebKit 实现的 Blob 文件持久化问题。播放器从本地字节生成临时 Blob URL。文字修改不替换录音，关闭编辑对话框时暂停并释放其中播放器。

## 跨设备计时控制

活动计时从所有已同步的未结束会话推导；另一设备看到同一个会话 ID 和开始时间后，可暂停、继续、补备注、结束，以及勾选计划完成。发起 deviceId 仅表示来源，不限制控制。计时控制字段按同一因果快照合并；并发结束优先于暂停/继续，已结束的会话不能被迟到的继续操作重新打开。备注等文字独立合并，操作日志仍完整保留。旧局部补丁按选定动作的因果祖先还原；旧备份仍需与旧合并或新合并结果严格匹配才可恢复。

两台设备需更新程序并连接相同 Google 账号和客户端 ID。3.0 仅手动同步：连接只授权，保存、回前台和联网不触发 Drive 请求。记录设备点“立即同步”后，其他设备再点“立即同步”取得共享计时状态。通知提醒投影独立更新。授权过期需用户点击重连，不自动弹窗或持久化 token。离线同时新开多个会话时保留并显示所有活动，供用户逐一结束。

## 同步与备份

录音使用独立不可变 Drive 文件，保留预分配文件 ID，并在上传后按 SHA-256 回读校验；录音确认后才上传引用它的操作日志。接收端下载并校验录音，重复同步复用文件。网络失败保留本地录音及队列，状态不会将失败标成已同步。首次真实手机语音跨端仍需真机确认。

电脑 Pocket 在本机交换前上传录音到受 Host/Origin/token 保护的接口；同文件相同字节幂等，不同字节拒绝覆盖。录音保存到原桌面 attachments 目录，桌面记录编辑器支持播放。原有图片/PDF 等附件同步未在本次扩展。

Dexie v3 追加 media / remoteMedia 表；v4 加入暂停区间，v5 加入可选的会话 note 字段；保留所有 v1/v2/v3/v4 表与既有记录，不重建资料库。会话增加可选 pauses 区间，旧会话没有该字段时按原始时长计算；暂停区间随操作日志、桌面交换及备份传输。手机和电脑均需更新程序，才能正确扣除暂停时间。JSON 备份仍为 schemaVersion 1，增加可选 media 数组（Base64、大小、MIME、SHA-256）；新版本支持旧备份，并在导入写入前校验全部录音。记录、日志和录音事务合并，编号冲突拒绝覆盖。导入/导出上限 128MB。

## 清理测试数据

用户明确要求清理时，对当时的 5 条记录、1 个固定测试事项、1 个完成状态和 3 段旧计时写入稳定 ID 的删除操作，保留历史墓碑，防止旧设备再次同步时复活。先保存 SQLite 一致性快照与完整结构化资料到仓库外 E 盘备份目录，不删除数据库或清理整个 Drive。其他记录不纳入清理范围。

这些删除操作需要经过电脑和手机同步后到达各设备；不通过清除网站数据或重装应用来更新。

## 验证边界

自动化覆盖本地/云端幂等、语音字节备份与恢复、故障重试、已删除会话不计时、可编辑日程及历史、离线启动、窄屏与键盘操作。Chromium 使用真实 MediaRecorder 编码和播放器验证；Windows Playwright WebKit 本身缺少 getUserMedia、MediaRecorder、AudioContext，因此录音场景使用明确的 WAV 夹具验证界面、字节持久化及传输，不代表 iPhone 原生麦克风验收。iPhone 主屏幕录音权限、系统中断及真实 Google Drive 语音闭环需用户真机完成。

界面仅保留操作、数据和必要状态；日程的大标题/标语区、项目图标及各页说明性文案已移除。

日程卡片本身用于开始/停止，不另显示开始文字；活动卡片没有绿色边框。

编辑弹窗按视口宽度与高度自适应，保留安全边距和内部纵向滚动；日期与备注输入框统一宽度，手机输入文字使用 16px 字体，避免聚焦时自动缩放。

日期浏览栏位于“当日记录”标题下方，只筛选记录与该日期的总时长。固定项目及其累计用时始终按今天计算，计划区保留未来计划，新增计划默认今天。日期输入时局部更新历史，保留日期选择器，避免后台列表刷新造成回跳。

通知状态：当前尚未接入通知订阅和后台定时推送。iOS 16.4+ 的主屏幕 Web App 可以在用户点击后请求通知权限；要在锁屏或关闭页面后提醒，还需服务端 Web Push 调度。[Apple WebKit 官方说明](https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/)。填写计划时间本身不会触发系统通知。
