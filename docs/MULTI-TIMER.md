# 多项目同时计时

固定项目和计划项目都可以同时计时。点击任一项目即可开始，不必先结束其他项目；顶部为每个正在计时或暂停的项目显示独立卡片。

- 每张卡片分别暂停、继续、结束，并可点击卡片编辑本段备注。
- 同一项目再次开始会复用已有未结束会话，不重复开一段。
- 勾选完成计划只结束该计划的会话；其他项目继续运行。结束计时仍不代表完成计划。
- 每段有效时长扣除自身暂停，不超过 30 秒仍不进入历史。
- 刷新、离线重开、JSON 备份与手动 Drive 同步都保留各个计时状态。

例如创建计划“洗衣服”并开始，再开始固定项目“学习”。洗衣服可以持续计时，学习单独暂停或结束；取完衣物后再结束洗衣计时并勾选完成。不需要配置或推进阶段。

## 统计

每个项目分别累计自己的有效时间。重叠时段会分别计入对应项目，当日总计为项目用时之和，可能超过当天实际经过的时间；不把重叠时段自动归给某一个项目。

## 旧后台流程

后台流程入口、阶段配置和阶段提醒已取消。此前流程本来就是原 task 记录，现在直接显示为普通计划，可继续编辑备注和计时；原有人工会话、完成状态和历史保留。旧阶段元数据仅为备份、因果日志及通知重复提交兼容而保留，不再控制计时或触发提醒，也不把旧等待时段补造为会话。

计划按可选详细时间触发的常规通知保持。旧通知投影保留原字段，确保相同操作 ID 的重复提交内容一致，不会因为移除阶段功能导致所有通知更新报冲突。

## 实现

沿用 `sessions`，不新增表、数据库或备份版本。`startSession` 在事务中按 subjectKind + subjectId 查找本项目未结束会话，不再锁定其他项目。界面从全部未结束会话推导所有计时卡片；旧 local.activeSession 只保留为兼容提示，不作为唯一活动来源。

人工会话的共享控制仍按同一稳定 ID、起止及暂停快照合并，结束优先于并发的旧继续操作。不同设备分别新开项目可以合并为多个活动；同一项目离线并发产生不同会话时仍保留原记录，供用户分别结束。

Google Drive 仍为手动：记录设备点“立即同步”，另一设备再点“立即同步”才能取得最新状态，不恢复后台轮询或自动双控。
